# Đa ngôn ngữ (i18n)

App dùng **[next-intl](https://next-intl.dev)** (App Router). **Mặc định: Tiếng Việt**; **English** qua prefix `/en` hoặc nút đổi ngôn ngữ.

## Cấu hình nhanh

| Thành phần                             | Vai trò                                                                                                                           |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `src/i18n/routing.ts`                  | `locales`, `defaultLocale` (`vi`), `localePrefix: 'as-needed'` (locale mặc định không có prefix trên URL).                        |
| `src/i18n/request.ts`                  | `getRequestConfig` — nạp `messages/{locale}.json`.                                                                                |
| `src/i18n/navigation.ts`               | `Link`, `redirect`, `useRouter`, `usePathname`, `getPathname` — **luôn dùng cho route nội bộ** thay vì `next/link` để giữ locale. |
| `messages/vi.json`, `messages/en.json` | Chuỗi UI; **cùng cấu trúc key** giữa hai file.                                                                                    |
| `next.config.ts`                       | `createNextIntlPlugin("./src/i18n/request.ts")`.                                                                                  |
| `src/middleware.ts`                    | `createMiddleware(routing)` rồi `updateSession(request, response)` — xem `docs/ARCHITECTURE.md`.                                  |

## Quy tắc copy (dễ maintain, dễ scale)

1. **Không hardcode** chuỗi hiển thị trong component (trừ log/debug hoặc hằng kỹ thuật không cần dịch).
2. **Namespace theo màn hình / vùng UI:** ví dụ `Meta`, `Header`, `Home`, `LivePage`, `Rtt`, `LocaleSwitcher`. Thêm feature mới → thêm namespace mới hoặc mở rộng namespace có sẵn; tránh một file JSON phẳng hàng trăm key không nhóm.
3. **Đặt tên key:** `camelCase`, mô tả vai trò (`ctaLive`, `statusConnecting`) chứ không copy nguyên câu làm tên key.
4. **Chuỗi có `<code>` hoặc format đặc biệt:** tách thành nhiều key (`subtitleBefore` / `subtitleAfter`) hoặc `t.rich` khi cần markup phức tạp — tránh nhét HTML thô vào JSON.
5. **Tham số động:** dùng ICU trong JSON, ví dụ `"errWs": "… {url} …"`, gọi `t('errWs', { url })`.
6. **Server Component:** `getTranslations('Namespace')` từ `next-intl/server`.
7. **Client Component:** `useTranslations('Namespace')` từ `next-intl`.
8. **Metadata / `<html lang>`:** `generateMetadata` và `getLocale()` trong layout — đã gắn với locale hiện tại.

## Mở rộng locale (ví dụ `ja`)

1. Thêm `'ja'` vào `routing.locales` trong `src/i18n/routing.ts`.
2. Thêm `messages/ja.json` (copy từ `en.json` rồi dịch).
3. Chạy `npm run build` — `generateStaticParams` trong `app/[locale]/layout.tsx` lấy locale từ `routing`.

## VALSEA / ASR

Ngôn ngữ nhận dạng giọng nói có thể khác ngôn ngữ UI. Hiện tại map đơn giản: locale `en` → `language: english`, còn lại → `vietnamese` (xem `app/[locale]/live/page.tsx`). Khi cần thêm ngôn ngữ ASR, mở rõ map hoặc chọn theo user setting.
