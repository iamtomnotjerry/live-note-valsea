# Đa ngôn ngữ (i18n)

App dùng **[next-intl](https://next-intl.dev)** (App Router). **Mặc định: Tiếng Việt** (`vi`). Các locale UI: **`vi`**, **`en`**, **`id`** (Bahasa Indonesia), **`th`** (ไทย), **`ms`** (Bahasa Melayu) — đổi qua prefix URL (khi khác locale mặc định) hoặc **LocaleSwitcher** (`localePrefix: 'as-needed'` nên `vi` không có prefix).

## Cấu hình nhanh

| Thành phần                       | Vai trò                                                                                                                                                                                                      |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `src/i18n/routing.ts`            | `locales`, `defaultLocale` (`vi`), `localePrefix: 'as-needed'`.                                                                                                                                              |
| `src/i18n/request.ts`            | `getRequestConfig` — nạp `messages/{locale}.json`.                                                                                                                                                           |
| `src/i18n/navigation.ts`         | `Link`, `redirect`, `useRouter`, `usePathname`, `getPathname` — **luôn dùng cho route nội bộ** thay vì `next/link` để giữ locale.                                                                            |
| `messages/*.json`                | Chuỗi UI; **cùng cấu trúc key** mọi file locale.                                                                                                                                                             |
| `scripts/gen-sea-ui-locales.mjs` | Sinh / đồng bộ **`id.json`**, **`th.json`**, **`ms.json`** từ `en.json` (chạy: `node scripts/gen-sea-ui-locales.mjs`). Sau khi thêm key mới vào `en.json`, chạy lại script hoặc cập nhật tay cả ba file SEA. |
| `next.config.ts`                 | `createNextIntlPlugin("./src/i18n/request.ts")`.                                                                                                                                                             |
| `src/middleware.ts`              | `createMiddleware(routing)` rồi `updateSession(request, response)` — xem `docs/ARCHITECTURE.md`.                                                                                                             |
| `src/app/layout.tsx`             | `getLocale()` → `html lang`; font **Noto Sans Thai** chỉ tải khi `locale === "th"` (Nunito không có glyph Thái trong `next/font`).                                                                           |

## Quy tắc copy (dễ maintain, dễ scale)

1. **Không hardcode** chuỗi hiển thị trong component (trừ log/debug hoặc hằng kỹ thuật không cần dịch).
2. **Namespace theo màn hình / vùng UI:** ví dụ `Meta`, `Header`, `Home`, `LivePage`, `Rtt`, `LocaleSwitcher`, **`Loading`** (nhãn `aria-label` cho skeleton route trong `loading.tsx`), **`LocaleSwitcher.switching`** (khi đổi locale). Thêm feature mới → thêm namespace mới hoặc mở rộng namespace có sẵn; tránh một file JSON phẳng hàng trăm key không nhóm.
3. **Đặt tên key:** `camelCase`, mô tả vai trò (`ctaLive`, `statusConnecting`) chứ không copy nguyên câu làm tên key.
4. **Chuỗi có markup hoặc đoạn nhấn mạnh:** ưu tiên **một key** đoạn văn đầy đủ (ví dụ `LivePage.subtitle`) để dễ dịch; nếu cần chèn `<code>` / bold giữa câu thì dùng **`t.rich`** hoặc tách key tối thiểu — tránh nhét HTML thô vào JSON.
5. **Tham số động:** dùng ICU trong JSON, ví dụ `"saveSuccess": "Saved (ref {ref})."`, gọi `t('saveSuccess', { ref })`. Chỉ thêm placeholder khi copy thật sự cần biến — đừng để `{param}` trong chuỗi mà code không truyền.
6. **Server Component:** `getTranslations('Namespace')` từ `next-intl/server`.
7. **Client Component:** `useTranslations('Namespace')` từ `next-intl`.
8. **Metadata / `<html lang>`:** `generateMetadata` và `getLocale()` trong layout — đã gắn với locale hiện tại.

## Mở rộng locale (ví dụ `ja`)

1. Thêm `'ja'` vào `routing.locales` trong `src/i18n/routing.ts`.
2. Thêm `messages/ja.json` (copy từ `en.json` rồi dịch); cập nhật `LocaleSwitcher` trong mọi file `messages/*.json`.
3. Chạy `npm run build` — `generateStaticParams` trong `app/[locale]/layout.tsx` lấy locale từ `routing`.
4. Nếu locale cần webfont đặc thù (như `th`), cân nhắc thêm biến font trong `layout.tsx` + quy tắc trong `globals.css`.

## VALSEA / ASR

**Ngôn ngữ nhận dạng giọng nói tách khỏi locale URL:** trên trang Live, người dùng chọn mã ASR trong panel (danh sách trong `valsea-rtt-language-options.ts`, state trong `live-rtt-panel.tsx`). Không map cứng “locale UI → một ngôn ngữ ASR”.
