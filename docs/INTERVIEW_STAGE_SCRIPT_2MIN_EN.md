# Interview Prep Coach - Stage Script (2 Minutes, English)

Use this as a read-aloud script while operating the app live.

## 0:00 - 0:15 (Opening)

"Hello judges. We built **Interview Prep Coach** for Vietnamese candidates preparing for foreign companies, especially Korean teams.  
The core problem is not only language - it is lack of structured, repeatable interview practice with actionable feedback."

## 0:15 - 0:30 (Setup on screen)

Action:

- Open `/en/interview`
- Select `Software Engineer`, `Mid`, `English`
- Click **Start interview**

Say:
"In one flow, users choose track, level, and language, then start a guided mock interview."

## 0:30 - 1:00 (Question 1 answer)

Action:

- Click **Start recording**
- Speak this sample answer
- Click **Stop recording**
- Click **Analyze this answer**

Suggested spoken answer:
"In my previous project, we had frequent release delays because bug triage was unclear.  
My task was to improve delivery predictability.  
I introduced a daily status update format, clarified severity definitions with QA, and reported blockers early with ETA.  
As a result, we reduced release delay by about thirty percent in two sprints."

Say:
"The system captures voice in real time, then runs AI steps: clarify, interview notes, action items, sentiment, and rubric scoring."

## 1:00 - 1:30 (Show feedback + Korean-style value)

Action:

- Show score card and feedback panel

Say:
"Our scoring is tuned for Korean workstyle expectations: ownership, clear reporting cadence, blocker communication, and commitment with ETA - not just fluent English.  
So users get practical improvement points they can apply in real interviews."

## 1:30 - 1:50 (Close loop with persistence)

Action:

- Finish second question quickly (voice or typed fallback)
- On summary, click **Save report**
- Open saved note

Say:
"After each session, candidates get a persistent report with strengths, weak points, and next actions.  
This makes interview prep measurable across multiple practice rounds."

## 1:50 - 2:00 (Final line)

"Interview Prep Coach turns random practice into structured coaching, with realtime AI feedback and clear business-ready outcomes. Thank you."

## Backup line if mic fails

"For reliability, we support manual text input fallback and keep the same AI evaluation pipeline."
